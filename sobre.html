Sobre o Sistema

Este sistema foi desenvolvido para controlar as finanças de uma equipe esportiva amadora.

O usuário pode cadastrar entradas e saídas financeiras, visualizar todos os lançamentos, excluir registros e acompanhar automaticamente o saldo da equipe.

Os dados são armazenados utilizando Local Storage, permitindo que permaneçam salvos mesmo após fechar o navegador.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • Bootstrap 5
  • JavaScript
  • Local Storage
